# Lunch App

Social app for getting lunch with friends on campus.

## Setup
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file in the root (get the values from the team chat)
4. Run `npm run dev`

## Workflow
- Never push directly to main
- Create a branch for your feature: `git checkout -b feature-name`
- Open a pull request when ready and ask a teammate to review
